# Code of conduct

Short version: **argue with the claim, not the person.**

## The standard

This repository exists because a field filled up with confident, unsourced advice. The correction
for that is not politeness, it is evidence. So:

- **Disagreement is welcome and expected.** The priority order and the terminology lock are
  judgements. They are stated as judgements so they can be argued with.
- **Bring a source or bring a labelled inference.** "I think" is fine when it says "I think".
  "Studies show" without a study is not.
- **Being wrong is normal here.** Several pages exist specifically to record that a popular tactic
  did not hold up. If your correction shows the maintainer wrong, that is the system working, and it
  will be merged and credited.
- **Do not attack people.** Not contributors, not the authors of research being critiqued, not
  vendors. A vendor publishing self-serving research gets a `⚠ Vendor` flag, not an insult.

## Not acceptable

Harassment, personal attacks, discriminatory language, or persistent bad-faith argument after a
point has been addressed. Also: submitting content you did not write without attribution, and
inventing sources.

**Fabricating a citation is the one thing that gets you removed immediately.** It is the specific
harm this project exists to counter.

## Enforcement

Report to the maintainer through a GitHub issue or by contacting
[@omarmfouad25](https://github.com/omarmfouad25) directly. Reports are handled privately.
Consequences run from a request to edit, through closing a thread, to a block.

This is a small project. It is run on judgement, in good faith, and imperfectly.
